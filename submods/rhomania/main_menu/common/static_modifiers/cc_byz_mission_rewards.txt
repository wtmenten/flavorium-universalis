# Short-duration reward modifiers for the mission tree's stepping stones.
#
# SIX SHARED MODIFIERS, NOT TWENTY-SIX. Every small task draws from this pool rather than
# defining its own, because twenty-six near-identical entries would be twenty-six things to
# keep balanced and twenty-six more lines in a tooltip when several are live at once.
#
# These are deliberately small and deliberately temporary. The long-lived, structural
# modifiers belong to the nine cornerstone tasks (see cc_byz_reconquest_modifiers.txt); a
# stepping stone should feel like a good year, not a permanent upgrade. Applied with
# mode = add_and_extend so completing several tasks on one theme extends the window rather
# than silently doing nothing.
#
# All names checked with tools/vanilla_search.py modifier <name>.
