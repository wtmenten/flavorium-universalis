# Country modifiers for the reconquest.
#
# Each theatre grants a permanent modifier reflecting what holding it actually gives the
# empire, and the theatre effects charge cc_byz_strain alongside. The modifiers are
# deliberately modest: the reward for a theatre is the ground and the CB it opens, not a
# stacking bonus. Four theatres held at once should be an achievement, not a multiplier.
#
# All names checked with tools/vanilla_search.py modifier <name>.

# ---- The eastern branch ----
