# The one modifier the Mamluk confrontation grants.
#
# Everything else in the situation is expressed through the progress counters, the pressure
# score and the pentarchy seats, which already carry vanilla's own add_pentarchy_modifier
# bonuses. Adding more country modifiers on top would be paying twice for the same conquest.

# All five seats held: Constantinople, Rome, Jerusalem, Antioch and Alexandria. This is the
# state vanilla's mend_schism requires, and reaching it is the end of a chain that runs through
# the exarchate (Rome) and this situation (the eastern three).

	game_data = {
		category = country
	}

	monthly_religious_influence = 0.15
	tolerance_own = 2
	monthly_prestige = 0.08
	clergy_estate_target_satisfaction = 0.1
	diplomatic_reputation = 1
}


# ---- The frontier and Cairo's weather: what the choices actually leave behind ----
#
# WHY THESE EXIST, AND WHY THE HEADER ABOVE NEEDED CORRECTING.
#
# This file used to say that everything besides the pentarchy was expressed through the
# progress counters and the pressure score, and that adding country modifiers on top would be
# paying twice. That reasoning had a hole in it: the counters live on the SITUATION, and the
# situation had no panel, so the counters were invisible. Every option on .4 and .5 paid out
# into a number the player could not see. Playtesting duly reported the events as "not
# impactful", which they were not, and would still not have been once the panel existed,
# because a progress bar is not a reason to prefer one option over another.
#
# The counters remain the situation's spine. These are what the player gets in the meantime.
# Modest and time-limited by design: the confrontation runs for centuries and these fire twice
# a generation, so anything large here would compound into the dominant source of everything.

# .4a. The border emirs bought. They hold the line for as long as the money lasts, which is
# what buying a frontier gets you and why it has to be bought again.
cc_byz_emirs_retained = {
	game_data = {
		category = country
	}
	global_manpower_modifier = 0.05
	levy_recovery_modifier = 0.10
}
