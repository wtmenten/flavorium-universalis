# Permanent modifiers for the mission tree's capstone tier.
#
# NINE ENTRIES, AND DELIBERATELY NOT MORE. These are applied with years = -1 and never expire,
# so every one of them is a line in the player's country modifier list for the rest of the
# campaign. Handing them out to stepping stones would produce a tooltip nobody reads and a
# balance nobody can reason about; the stones draw from the six temporary pools in
# cc_byz_mission_rewards.txt instead.
#
# WHICH TASKS. The three pillar capstones, the three reconvergences, the Anatolian
# reconvergence, the optional city capstone, and Greek Fire. The NINE THEATRE CORNERSTONES ARE
# NOT HERE: they already carry permanent modifiers through cc_byz_theatre_*_effect in
# scripted_effects/cc_byz_theatre_effects.txt, which both front-ends call. Adding a second
# permanent modifier to those would double-pay the mission-mode player for work the
# generic-action player does for one.
#
# SIZING. Each is roughly one temporary pool's worth of effect, made permanent. That is
# intentionally modest: the reward for a capstone is mostly that it opens the next branch, and
# these should read as the empire being structurally better at something rather than as a prize.
#
# All modifier names checked with tools/vanilla_search.py modifier <name>. Note bank_interest
# is inverted (negative is cheaper) and fort_maintenance_efficiency flipped sign in 1.3
# (efficiency up means cheaper), both per docs/scripting-gotchas.md.


# ---- The three pillar capstones ----

# The Logothete of the Course. The assessment is current, the offices are staffed, and the
# treasury knows what it is owed before it is owed it.
cc_byz_perm_logothete = {
	game_data = {
		category = country
	}

	tax_income_efficiency = 0.05
	global_bureaucracy_maintenance_efficiency = 0.10
	country_cabinet_efficiency = 0.05
}

# The Ecumenical Throne. The patriarch is the emperor's, and the daughter churches know it.
cc_byz_perm_ecumenical = {
	game_data = {
		category = country
	}

	monthly_religious_influence = 0.05
	tolerance_own = 0.5
	global_estate_satisfaction_from_legitimacy = 0.05
}

# Pontifex Maximus. The Hellenic pair of cc_byz_perm_ecumenical above, granted by
# cc_byz_task_pontifex, and deliberately the same shape: the two tasks ask the same question
# (does the emperor's religious authority actually reach) and should pay the same way.
#
# ADDED AFTER A REPORTED LOAD ERROR:
#   PostValidate of effect 'add_country_modifier' returned false
#   at common/missions/cc_byz_renovatio_campaign.txt:568
# The task granted this and nothing defined it. Its LOCALISATION was written, which is why the
# omission survived: a missing-loc-key audit finds nothing when the key exists and the thing it
# names does not. The undefined-modifier sweep that would have caught it was run before the
# Hellenic tasks were added and never re-run afterwards.
cc_byz_perm_pontifex = {
	game_data = {
		category = country
	}

	monthly_religious_influence = 0.05
	tolerance_own = 0.5
	global_estate_satisfaction_from_legitimacy = 0.05
}
