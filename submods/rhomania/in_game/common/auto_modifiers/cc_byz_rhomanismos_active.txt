# Conditional half of the Rhomanismos advance payoffs.
#
# See the header of in_game/common/advances/cc_byz_rhomanismos.txt for why these are split.
# Short version: BYZ starts around +80 so the whole line is researched at game start, and
# advance modifiers are permanent once researched, while vanilla's rom_* line is sticky via
# has_or_had_tag = ROM. Without this the player holds both lines at once. We cannot block
# vanilla's ROM formable, so the payoff has to be what reacts.
#
# Each advance keeps a small permanent core on the advance itself. The larger share is here,
# gated on both having researched it and still running the empire as a Rhomaios one. Abandon
# the axis and these switch off; return to it and they come back. The advance is knowledge,
# which you keep. These are the institution actually functioning, which you do not.
#
# The +25 threshold matches the allow blocks on the advances themselves. Keep the two in
# sync: an advance researchable at a threshold its payoff does not honour is a trap.

#############################
# age_1_traditions
#############################

	potential_trigger = {
		has_societal_value = societal_value_type:latinization_vs_hellenization
		has_advance = cc_byz_taxis_of_offices
		societal_value:latinization_vs_hellenization > 25
