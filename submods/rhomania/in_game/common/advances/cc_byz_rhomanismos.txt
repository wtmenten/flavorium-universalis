# Rhomanismos advances: the Greek-side answer to country_ROM.txt.
#
# Vanilla's rom_* line is gated on has_or_had_tag = ROM, and the only route to that tag for
# a Byzantine player is ROM_BYZ_f, which force-moves the capital to Rome and applies
# societal_value_huge_move_to_left. Every unique payoff in the pack therefore sits behind
# abandoning Constantinople. This line answers each rom_* advance from the Rhomaios side,
# available to a player who never leaves the capital.
#
# GATING. potential is deliberately stable (dlc, tag, has_societal_value) and the live
# societal value check lives in allow. No vanilla advance gates potential on a value's
# numeric position, and doing so would make advances appear and vanish as the value drifts.
# With the check in allow the advance stays visible and greys out, which also tells the
# player what the requirement is. Advances support allow: see 0_age_of_absolutism.txt:25.
#
# The +25 threshold is the Rhomanismos side of a -100..100 axis. Vanilla uses comparable
# cutoffs at -50 (restore_rome_primacy) and +/-90 (reestablish_hellenism).
#
# WHY THE PAYOFFS ARE SPLIT. BYZ starts around +80, so these are all researched at game
# start, and an advance's modifiers are permanent once researched. Vanilla's rom_* line
# gates on has_or_had_tag = ROM, which is sticky forever. Left alone that means a player
# takes this line free in 1337, Latinizes in 1500, forms ROM, and holds BOTH lines
# permanently, which is strictly dominant and defeats the point of the pillar. We cannot
# block vanilla's formable (no vanilla overrides), so the payoff itself has to be the thing
# that reacts.
#
# So each advance keeps only a small permanent core here (the knowledge, and enough that
# the tech-tree tooltip is never empty), and the bulk lives in auto_modifiers in
# cc_byz_rhomanismos_active.txt gated on has_advance = <this> AND the value still being
# above +25. Latinize and the bulk switches off while the advance itself remains.
# The tagmata units carry the same check in their own country_potential, since unit
# availability cannot be driven from an auto_modifier.

############################
# age_1_traditions
############################

# Answers rom_spqr (parliament_base_support). Rome's reply to power-sharing was the Senate;
# the Rhomaios reply is the graded hierarchy of court dignities, which binds the powerful
# to the palace by making rank something the emperor alone can confer.
cc_byz_taxis_of_offices = {
	age = age_1_traditions
	potential = {
		has_dlc = "d008_fate_of_the_phoenix"
		has_or_had_tag = BYZ
		has_societal_value = societal_value_type:latinization_vs_hellenization
	}
	allow = {
		societal_value:latinization_vs_hellenization > 25
	}
	requires = distribution_of_power_advance

	icon = crown_power_advance_renaissance

	monthly_legitimacy = 0.05
}
