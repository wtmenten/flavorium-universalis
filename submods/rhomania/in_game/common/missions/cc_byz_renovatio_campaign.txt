# FRONT-END 2: the mission tree, for players with mission packs ON.
#
# 86 tasks. A spine with three braided pillars, four gateways, five exclusive forks, four
# reconvergence points and eleven optional spurs.
#
# NO NODE HAS MORE THAN FOUR VISIBLE CHILDREN. Verified by walking the requires graph; the two
# nodes at five raw children (Anatolia Secured, The Latin Powers) each have an exclusive fork
# among them, and a fork shows one sibling at a time.
#
#
# READ THIS BEFORE ADDING A TASK.
#
# 1. REWARDS GO IN on_persistent_completion, NEVER on_completion. Per common/missions/
#    ____Info.txt, on_completion "is not executed if task_rewards_disabled is active in the
#    rules" while on_persistent_completion "is ALWAYS executed". The mission_rewards rule
#    defaults to only_end_mission_rewards, which sets task_rewards_disabled. Using
#    on_completion silently drops the reward under DEFAULT settings.
#
# 2. ONLY THE NINE CORNERSTONES HAVE A GENERIC-ACTION TWIN. Everything else is mission-mode
#    only and is not compensated for elsewhere. Mission packs are OFF by default; the
#    cornerstones and their permanent modifiers remain reachable either way, which is the part
#    that matters. See generic_actions/cc_byz_theatre_actions.txt.
#
# 3. Only ONE task may carry final = yes. That is cc_byz_task_mare_nostrum.
#
# 4. PERMANENT MODIFIERS ARE CAPSTONE-TIER ONLY. Nine of them, defined in
#    static_modifiers/cc_byz_mission_capstones.txt, on the three pillar capstones, the three
#    reconvergences, Anatolia Secured, The City Adorned and Greek Fire. Stepping stones draw
#    from the six TEMPORARY pools in cc_byz_mission_rewards.txt. The nine theatre cornerstones
#    are excluded because cc_byz_theatre_*_effect already gives them permanent modifiers, and
#    a second one would pay the mission-mode player twice for what the action-mode player does
#    once.
#
#
# THE FIVE STRUCTURES, and how each is expressed.
#
# GATEWAY. The State Restored used to have TWELVE direct children, which made the third rank of
# the tree unreadable. Four gateways now sit between it and that cluster: The Roman Title, The
# Balkan Frontier, The Latin Powers and The Anatolian Return. Each is a small objective in its
# own right rather than a pure connector, and no node in the tree now has more than four
# children. Nothing downstream needed rewriting, because requires is AND across the whole pack
# and not just within a branch: Illyricum still names Despotate, No Second Emperor and Adriatic
# even though those three now hang off two different gateways.
#
# ANY ORDER. Several tasks share one requires parent and reconverge later. The three western
# theatres all require only cc_byz_task_illyricum, so Italy, Africa and Spania can be taken in
# whatever order the map offers. This is also the historical order: Justinian took Africa in
# 533 and Italy afterwards, which the old strict chain forbade.
#
# RECONVERGENCE. requires = { a b c } is AND, so a task naming several parents waits for all
# of them. Vanilla does this (generic_conquer_province_mission_pack.txt:284, three parents).
#
# SUBSET (two of three). There is no count operator for mission_task_completed, so the test is
# an explicit OR of AND pairs wrapped in a custom_tooltip. The player reads one clean line and
# never sees the nine. Deliberately NOT done with a counter variable: a counter is derived
# state, bypassed tasks fire on_bypass rather than on_persistent_completion, and this tree
# bypasses a great deal (every fork sibling, every stone that can become impossible). A
# desynced counter would either unlock a branch early or block it forever with nothing in the
# log. mission_task_completed is stateless and reads the truth at every evaluation.
#
# EXCLUSIVE FORK. Five of them. Each sibling carries:
#     visible = { NOT = { mission_task_completed = mission_task:<other> } }
#     bypass  = { mission_task_completed = mission_task:<other> }
# The visible hides the road not taken, exactly as vanilla does at
# generic_capital_economy_mission_pack.txt:270. The bypass is load-bearing rather than
# cosmetic: without it a reconvergence naming either sibling would wait forever on the one
# that can no longer complete.
#
#
# BYPASS ON UNREACHABLE CONDITIONS. Any task depending on owning one specific place carries a
# bypass, because gating means one impossible stone would block its whole branch. Tasks whose
# condition only gets easier with time (a NOT-exists, an income threshold) need none.
#
#
# TASKS THAT ARE TRUE AT GAME START ARE NOT TASKS. Six were, and every one had the same shape:
# a condition that reads like an objective and is already satisfied in 1337. Recorded here
# because the checks are not obvious from the trigger names.
#
#   any_work_of_art IS THE WORLD ITERATOR. "Iterate through all WorkOfArts in the world"
#   (trigger.md:364). It has no country filter at all, so count >= 3 counted every artwork on
#   the map. This is also why any_work_of_art_count has no localisation: vanilla localises
#   any_work_of_art_in_country_count and any_work_of_art_in_location_count and never the world
#   form, because nothing sane uses it. Both art tasks now use the country iterator.
#
#   EVEN THEN A BARE COUNT DOES NOT WORK. BYZ starts with NINE works of art totalling 503
#   quality (11_art.txt:86-94: Hagia Sophia 91, crown jewels 65, Hagia Irene 57, Syntagma
#   Canonum 51, Ecclesiastica Historia 51, Apoheteftiko 50, Theodosian Walls 48, Song of
#   Armouris 46, Paris Psalter 44). So the art tasks are keyed to quality, not count.
#
#   BYZ LEADS THE ECUMENICAL PATRIARCHATE FROM SETUP. 15_international_organizations.txt:547
#   creates it with seat = constantinople and sixty-odd members, BYZ among them. "Be the leader
#   of an autocephalous patriarchate" was therefore true before the player pressed unpause.
#
#   THE WALLS AND THESSALONIKI ARE OWNED AT START, so "has the walls" and "owns Thessaloniki"
#   were free. The walls now use duration; Thessaloniki now needs control.
#
#
# NO TASK USES duration. Every one of them is duration = 0.
#
# cc_byz_task_walls briefly used duration = 3650 to express "the walls must still be standing
# ten years on", and the mechanic turned out to be the wrong tool. duration is a progress timer
# on a task the player has already qualified for, not a condition, and its behaviour when the
# enabled trigger goes false again is undocumented: if the timer does not reset, the anti-cheese
# it was there to provide does not exist, and there is no way to tell from script which it does.
# Vanilla's whole range across fourteen generic packs is 30 to 730 days, so 3650 was also an
# order of magnitude outside anything Paradox has tested.
#
# The replacement is a hard date in enabled: current_date > 1347.1.1, ten years from the 1337
# start. It is a plain trigger with no hidden state, it reads correctly in the tooltip, and it
# says exactly what was meant, which is that the walls have to be standing in 1347 rather than
# merely at some point.
#
# Date form is current_date > 1347.1.1, matching vanilla (bubonic_plague.txt:39,
# guelphs_and_ghibellines.txt:8).
#
#
# THE BUREAU TASKS DO NOT TEST MAINTENANCE DIRECTLY. They used to, and it was cheesable in the
# most direct way available: fund every bureau for one month, let the task tick over, defund the
# next month, and the tree permanently records that the empire runs its bureaus properly.
#
# Both now read cc_byz_bureau_funding_avg, a five-year running mean maintained monthly off
# monthly_country_pulse (scripted_effects/cc_byz_bureau_funding.txt). The sample is the mean
# across EVERY bureaucracy the country has, funded or not, so four bureaus with one funded
# samples 0.25. The root task wants a five-year average of 50 percent, the Logothete capstone
# 75 percent. A single month of full funding moves the average by under two percent of the gap,
# so there is no burst of spending that reaches either.
#
#
# SHAPE
#
#   T0  House in Order      5 roots, any order
#   T1  Three pillars       Fisc / Faith / Sword, any order -> The State Restored (2 of 3)
#   T2  Four gateways       Roman Title / Balkan Frontier / Latin Powers / Anatolian Return
#   T3  Anatolia            FORK 2 destroy or vassalise the Turks, FORK 3 tagmata or pronoia
#   T4  The Levant          the seats (2 of 3), FORK 4 treaty or Pentarchy War
#   T5  The West            Illyricum -> Italy / Africa / Spania in ANY ORDER (2 of 3)
#   T6  The East            off the Sinai Road, FORK 5 monopoly or company
#   S   Spurs               11 optional, none gate anything
#
# ART. 85 icons are named and none are supplied. A missing .dds renders a BLANK button without
# logging, so this is checked by eye. Cornerstones and pillar capstones are worth doing first.

cc_byz_renovatio_campaign = {

	# T0. THE HOUSE IN ORDER. Five roots, any order, no wars required.

	# The only timed task in the tree. See the duration note in the header: the walls are owned
	# at the start date, so without a timer this completed on the first evaluation and the
	# player could then demolish them.
	cc_byz_task_walls = {
		icon = cc_byz_mission_army
		highlight = { scope:province = { this = location:constantinople } }
		enabled = {
			current_date > 1347.1.1
			location:constantinople = {
				owner ?= root
				has_building_with_at_least_one_level = theodosian_walls
			}
		}
		bypass = { NOT = { owns = location:constantinople } }
		duration = 0
		on_persistent_completion = {
			add_gold = 100
			add_country_modifier = { modifier = cc_byz_reward_fortifications  years = 15  mode = add_and_extend }
		}
	}

	cc_byz_task_hippodrome = {

		}

	# TWO funded bureaus, not four. Slot sources for BYZ are byz_bureaucracy_advance (+2,
	# age 1), the Greek/Orthodox legal-system law (+1), and a metropolis capital (+1), then
	# nothing until generic_bureaucracy_4_advance in AGE 4. Four funded bureaus is therefore
	# close to the practical ceiling for most of the campaign and belongs on the pillar
	# capstone, not on a root.
	cc_byz_task_bureaus = {
		icon = cc_byz_mission_coin
		enabled = {
			any_current_bureaucracy = { count >= 2 }
			custom_tooltip = {
				text = cc_byz_bureau_funding_avg_tt
				trigger_if = {
					limit = { has_variable = cc_byz_bureau_funding_avg }
					var:cc_byz_bureau_funding_avg >= 0.5
				}
				trigger_else = { always = no }
			}
		}
		duration = 0
		on_persistent_completion = {
			add_gold = 150
			add_country_modifier = { modifier = cc_byz_reward_administration  years = 20  mode = add_and_extend }
			add_country_modifier = { modifier = cc_byz_reward_credit  years = 20  mode = add_and_extend }
			change_societal_value = { type = cc_taxis_vs_cc_dynatoi  value = societal_value_minor_move_to_left }
		}
	}

	# COUNTRY iterator with a quality filter, not the world iterator with a bare count. At the

			add_country_modifier = { modifier = cc_byz_reward_confidence  years = 20  mode = add_and_extend }
		}
	}

	# Leading the Ecumenical Patriarchate is the START CONDITION, not the objective. The
	# objective is the daughter churches: hold the seat of a SECOND autocephalous patriarchate.
	# The nine seats at 1337 are Constantinople (ours), Tarnovo, Tbilisi, Nicosia, Sis, Antioch,
	# Alexandria, Mosul and Kollam; Tarnovo and Nicosia are the ones an early empire can reach.
	# Orthodox half of the pair with cc_byz_task_temples above. An autocephalous patriarchate
	# is an Orthodox institution and vanilla's IO type says so; there is no Hellenic reading of
	# it, which is why the sibling asks for sanctuaries instead.
	cc_byz_task_autocephalous = {
		icon = cc_byz_mission_church
		requires = { cc_byz_task_hippodrome }
		visible = { NOT = { cc_byz_faith_hellenic_trigger = yes } }
		bypass = { cc_byz_faith_hellenic_trigger = yes }
		enabled = {
			any_international_organizations_member_of = {
				international_organization_type = international_organization_type:autocephalous_patriarchate
				international_organization_has_leader = yes
				leader_country = root
			}
			custom_tooltip = {
				text = cc_byz_second_patriarchal_seat_tt
				OR = {
					owns_or_non_sovereign_subject_owns = location:tarnovo
					owns_or_non_sovereign_subject_owns = location:nicosia_cyp
					owns_or_non_sovereign_subject_owns = location:tbilisi
					owns_or_non_sovereign_subject_owns = location:sis
				}
			}
		}
		duration = 0
		on_persistent_completion = {
			add_religious_influence = 30
			add_prestige = prestige_mild_bonus
		}
	}

	# Foreign relations through religion, which nothing else in the tree covered. Three Orthodox
	# powers at real warmth, which for a Byzantium that has been fighting Serbia and Bulgaria is
	# a genuine change of policy rather than a formality.
	# EXCLUSIVE PAIR WITH cc_byz_task_old_rites BELOW. This one is genuinely about Orthodoxy as
	# an institution rather than about the empire's faith in general, so it is not converted to
	# the faith layer: it is hidden for a Hellenic emperor and bypassed so the branch still
	# flows. Same visible/bypass idiom as the sultans_friend / pentarchy_war fork.
	cc_byz_task_orthodox_concord = {
		icon = cc_byz_mission_church
		requires = { cc_byz_task_athonite }
		visible = { NOT = { cc_byz_faith_hellenic_trigger = yes } }
		bypass = { cc_byz_faith_hellenic_trigger = yes }

			any_country = {
				count >= 3
				religion = religion:orthodox
				NOT = { this = root }
				opinion = { target = root  value >= 100 }
			}
		}
		duration = 0
		on_persistent_completion = {
			add_religious_influence = 25
			add_prestige = prestige_mild_bonus
			change_societal_value = { type = latinization_vs_hellenization  value = societal_value_minor_move_to_right }
		}
	}

	# PILLAR CAPSTONE.
	# ---- THE OLD RITES: the Hellenic branch of the faith pillar ----
	#
	# WHY THESE EXIST. Fate of the Phoenix ships a complete, supported route out of Orthodoxy
	# (hellenism_religion_movement spawns at Hellenic holy sites held by Christian owners, and
	# the empire holds Delphi, Olympia, the Parthenon, Eleusis, Dodona and Delos). The submod
	# assumed Orthodoxy everywhere, so converting made six tasks impossible and took the faith
	# pillar's capstone down with them.
	#
	# THE EXCLUSIVE-PAIR IDIOM IS THE TREE'S OWN, copied from the sultans_friend / pentarchy_war
	# fork: visible hides the branch that does not apply, bypass lets it be skipped so the
	# requires-chain still flows through it. That combination is also what makes a MID-CAMPAIGN
	# conversion safe. An emperor who converts with the Orthodox faith pillar half finished has
	# the remainder bypassed and the Hellenic siblings appear in their place, and the tree
	# reflows rather than stranding him.
	#
	# The tree has no explicit positions, laying out from `requires` alone, so siblings added
	# here cannot collide with anything.

	# THE ON-RAMP, AND IT IS NOT A CONVERSION. Visible to an Orthodox emperor, because that is
	# the only kind of emperor who can reopen the Academy. It makes the question askable; the
	# answering is vanilla's movement, which this deliberately neither duplicates nor bypasses.

			average_country_literacy > 25

				OR = {
					owns_or_non_sovereign_subject_owns = location:athens
					owns_or_non_sovereign_subject_owns = location:constantinople
				}
			}
		}
		duration = 0
		on_persistent_completion = {
			add_prestige = prestige_mild_bonus
			trigger_event_non_silently = { id = cc_byz_hellenic.1 }
		}
	}

		# our call site.

	# The permanent modifier is granted by cc_byz_fire.3, not here, exactly as the nine theatre
	# cornerstones grant theirs inside cc_byz_theatre_*_effect rather than in the task.
	cc_byz_task_greek_fire = {
		icon = cc_byz_mission_army
		requires = { cc_byz_task_dromon }
		enabled = {
			navy_tradition >= 50
			average_country_literacy > 20
		}
		duration = 0
		on_persistent_completion = {
			add_navy_tradition = navy_tradition_mild_bonus
			trigger_event_non_silently = cc_byz_fire.1
		}
	}

	# --- The wonders, feeding an optional capstone ---

	cc_byz_task_hagia_sophia = {
		icon = cc_byz_mission_church
		requires = { cc_byz_task_hippodrome }
		highlight = { scope:province = { this = location:constantinople } }
		enabled = {
			location:constantinople = {
				owner ?= root
				has_building_with_at_least_one_level = cathedral
			}
		}
		bypass = { NOT = { owns = location:constantinople } }
		duration = 0
		on_persistent_completion = {
			add_religious_influence = 30
			add_country_modifier = { modifier = cc_byz_reward_confidence  years = 20  mode = add_and_extend }
		}
	}

	# country_art_quality, not a count. BYZ starts on 503 across nine works, so a count of six
	# was satisfied before the player pressed unpause.
	cc_byz_task_great_palace = {
		icon = cc_byz_mission_city
		requires = { cc_byz_task_hippodrome }
		enabled = { country_art_quality >= 800 }
		duration = 0
		on_persistent_completion = {
			add_prestige = prestige_mild_bonus
			add_legitimacy = legitimacy_mild_bonus
		}
	}

	# Thessaloniki is OWNED at the start date, so ownership alone was not an objective. Control
	# is: the second city sits at the far end of a road the empire has not policed in a century.
	cc_byz_task_thessaloniki = {
		icon = cc_byz_mission_reconquest
		requires = { cc_byz_task_walls }
		highlight = { scope:province = { this = location:thessaloniki } }
		enabled = {
			location:thessaloniki = {
				owner ?= root
				local_control >= 0.3
			}
		}
		bypass = { NOT = { owns = location:thessaloniki } }
		duration = 0
		on_persistent_completion = {
			add_gold = 100
			add_country_modifier = { modifier = cc_byz_reward_fortifications  years = 20  mode = add_and_extend }
		}
	}

	# THE OPTIONAL CAPSTONE. It used to carry enabled = { always = yes }, so it completed the
	# instant its three parents did and asked nothing of its own.
	cc_byz_task_city_adorned = {
		icon = cc_byz_mission_city
		requires = {
			cc_byz_task_hagia_sophia

			cc_byz_task_thessaloniki

			}

		bypass = { NOT = { owns = location:constantinople } }
		duration = 0
		on_persistent_completion = {
			add_prestige = prestige_severe_bonus

			add_estate_satisfaction = { type = estate_type:burghers_estate  value = estate_satisfaction_mild_bonus }
		}
	}

	# --- Dead ends with a reward ---

	# Hangs off the Sword capstone rather than off Illyricum. Illyricum had six children, which
	# made it the new widest node in the tree, and a triumph belongs to the army that earned it
	# rather than to a Balkan theatre.
	cc_byz_task_triumph = {
		icon = cc_byz_mission_army
		requires = { cc_byz_task_field_army }

		duration = 0
		on_persistent_completion = {
			add_prestige = prestige_severe_bonus
			add_estate_satisfaction = { type = estate_type:burghers_estate  value = estate_satisfaction_mild_bonus }
		}
	}

	# REPURPOSED. This used to exist solely to grant cc_byz_cb_recover_the_islands at 30
	# researched advances; the Merchant Fleet now grants that CB decades earlier, which left
	# this task with nothing to do. It is now the scholarly spur it always looked like.
	# Moved off Illyricum to the Fisc capstone for the same width reason as the Triumph, and it
	# reads better there: recovering the register of the old provinces is the logothete's work.
