# Country modifiers granted by the bureau thread (in_game/events/cc_bureau.txt).
#
# Applied with add_country_modifier = { modifier = X  years = N  mode = add_and_extend }, so a
# repeat grant refreshes the duration instead of stacking the magnitude. That matters here: the
# thread can offer the same route twice a century and the second grant must not double it.
#
#
# THESE CARRY THE THREAD'S SOCIETAL DRIFT rather than the option blocks doing it inline.
#
# The events push the Order/Magnates axis by granting one of these, not by calling
# change_societal_value, and there are two reasons. The drift belongs to the lasting state the
# decision created, so the player reads it in the same tooltip as its cause. And the durations
# were already chosen to match the fiction, so nothing has to be re-tuned separately.
#
# Rates against the instant scale: societal_value_move_to_left is -10 in one step, while
# minor_monthly_move is 0.05 a month, or 0.6 a year. A 25-year grant is therefore worth about 15
# points, half again as much as a jump, spread over long enough that the player can change
# course and undo it. That difference is the whole reason for preferring drift here.
#
# All keys are vanilla modifier names except monthly_towards_cc_order / cc_magnates, which are
# registered in main_menu/common/modifier_type_definitions/cc_societal_values.txt.
