###############################################################################
# CC TRAIT DISPATCH
#
# Single hidden country event replacing three independent monthly sub-pulses
# (cc_cabinet_monthly_traits, cc_cabinet_monthly_social_traits,
# cc_cabinet_monthly_age_traits). Fires every month via
# cc_cabinet_monthly_trait_dispatch.
#
# For each cabinet character not on the 2-year trait cooldown, one random_list
# pick gives that character at most one trait event per monthly tick.
#
# Character targeting: dispatcher sets cc_trait_dispatch_selected on the
# chosen character, fires the event at country scope via root, and the event's
# immediate block picks the character with that flag and removes it immediately
# so subsequent iterations find a clean state.
#
# CAREER ENTRY. Five of the branches below fire an event that can grant a ladder
# rung-0 trait, which is to say a CAREER: cc_traits.1, cc_cond.1, cc_cond.3,
# cc_cond.20 and cc_cond.31. Since the training return events began offering the
# player a career of their choosing (cc_xp.90/.91/.92), those five carry
#
#   modifier = { factor = 0.3  root = { is_ai = no } }
#
# so a human court's minister is much less likely to be committed to a random
# career before the player gets to pick one, while an occasional unasked-for
# career still happens. AI courts are untouched: nothing offers them a choice, so
# the random path is the only path they have.
#
# The other twenty-nine branches are deliberately NOT reduced. They grant age
# traits, afflictions, estate-faction traits and conditional flavour, none of
# which are ladder rungs and none of which the picker competes with.
###############################################################################

				# every month, and the handful of branches carrying no experience gate at all
				# (the five age events and integration) took nearly all of it.

				# At 300 the same minister faces 300-against-30, about 9%. Raise this number to
				# quieten the whole system; it is the one lever that does not change which
